# DiscussionBridge for Statamic

Publish between Statamic and Discourse and show forum discussions beside
your entries. The same addon supports Statamic 6 with Flat files, Eloquent
DB, or the official static site generator.

Install the addon through Composer, choose the profile your site uses, and
set up the Content Connection in Discourse. The [starter kit](starter-kit/)
shows how to add DiscussionBridge to a Statamic template. The [V4 configuration
guide](https://github.com/DiscussionBridge/statamic-discussion-bridge/blob/v0.4.0-alpha.1.statamic.4/README.md#configure)
has the install and configuration details. [Statamic platform guide](https://docs.discussionbridge.dev/platform-profiles/)
